# 🚗 Автосервис — Заказ-наряды (PWA)

Веб-приложение для автосервиса. Мастер-приёмщик создаёт электронный заказ-наряд и передаёт его автомеханику. Механик отмечает выполненные работы, добавляет фото (с камеры или из галереи) и рекомендации (можно голосом), после чего мастер закрывает наряд и отправляет в архив.

**🔗 [Развёрнуто на Render.com](https://auto-service.onrender.com)** *(обновите ссылку после деплоя)*

## Возможности

- 👑 **Админ-панель** — CRUD мастеров и механиков
- 🧰 **Мастер-приёмщик** — создаёт наряды, выбирает механика, видит фото и рекомендации
- 🔧 **Автомеханик** — видит только свои наряды, отмечает работы, **голосовой ввод**, **камера + галерея**, удаление фото
- 🖨 **Печатная форма A4** — кнопка «Распечатать» с правильным форматированием
- 🔔 **Push-уведомления** — при новом наряде, фото, рекомендациях, завершении
- 📱 **Mobile-friendly** — работает на iOS Safari, Android Chrome, Yandex Browser

## Стек

- **Backend:** Node.js 22 + Express + better-sqlite3 + bcryptjs + multer
- **Frontend:** Vanilla JS SPA (без сборки), Web Speech API (голос), `<input capture>` (камера/галерея)
- **Хранение:** SQLite + файлы на диске
- **Деплой:** готов под Render / Fly.io / Railway / VPS

## Роли

### 👑 Админ
- CRUD мастеров-приёмщиков (логин + пароль)
- CRUD автомехаников (ФИО + табельный номер)

### 🧰 Мастер-приёмщик
- Список заказ-нарядов с вкладками: **Активные / Выполненные / Архив / + Новый**
- Создание заказ-наряда: номер, марка/модель, VIN, гос-номер, пробег, ФИО клиента, запчасти (наши/клиента), механик из выпадающего списка, начальный список работ
- Детальный просмотр: работы с отметками, рекомендации механика, фото
- **Архивирование** (после выполнения — машина выдана клиенту)
- Push-уведомления о выполнении и о новых фото

### 🔧 Автомеханик
- Видит **только свои** заказ-наряды (доступ других механиков — `403`)
- Чек-лист работ с возможностью:
  - отметить выполнение
  - **удалить** работу
  - **добавить** новую (текст + трудоёмкость, **голосовой ввод** 🎤 через Web Speech API)
- Поле «Рекомендации» (сохраняются отдельно)
- **Прикрепление фото** с камеры телефона (`<input type="file" capture="environment">`)
- Кнопка «Все работы выполнены» → статус «Выполнен» → push мастеру

## Хранение

- SQLite в `data.db` (создаётся автоматически)
- Фото — на диске в `public/uploads/photos/o{orderId}_{timestamp}.{ext}`

## API (краткий обзор)

| Метод | Путь | Роль | Описание |
|-------|------|------|----------|
| POST | `/api/auth/login` | — | Логин (admin/master/mechanic) |
| GET | `/api/orders` | * | Список с фильтром `?status=` |
| GET | `/api/orders/:id` | * | Детали (с работами и фото) |
| POST | `/api/orders` | master | Создать заказ-наряд |
| POST | `/api/orders/:id/works` | master/mechanic | Добавить работу |
| PATCH | `/api/orders/:id/works/:wid` | master/mechanic | Отметить выполнение |
| DELETE | `/api/orders/:id/works/:wid` | master/mechanic | Удалить работу |
| PATCH | `/api/orders/:id/recommendations` | mechanic | Рекомендации |
| POST | `/api/orders/:id/photos` | master/mechanic | Загрузить фото |
| POST | `/api/orders/:id/complete` | mechanic | Закрыть наряд |
| POST | `/api/orders/:id/archive` | master | В архив |
| GET | `/api/notifications` | * | Список уведомлений |
| POST | `/api/notifications/read` | * | Пометить прочитанными |
| GET/POST/DELETE | `/api/admin/users` | admin | Управление пользователями |

## Ограничения прототипа

- **Нет HTTPS** — для прода нужен reverse-proxy (nginx/Caddy) + Let's Encrypt
- **Polling** вместо WebSocket — для мгновенных push нужен Service Worker + VAPID
- **Токен в localStorage** — для прода лучше httpOnly cookie + CSRF
- **Фото без сжатия** — на больших снимках телефон отдаёт ~3-5 МБ, можно прикрутить sharp
